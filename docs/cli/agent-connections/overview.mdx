---
title: "Overview"
description: "Point the Calibrate CLI at an existing agent over HTTP or WebSocket"
---

Instead of defining an agent inside Calibrate, you can point the CLI at an agent you've already deployed. Set `agent_url` in your config JSON — the scheme decides the connection type.

Pick the connection that matches your agent:

<CardGroup cols={2}>
  <Card
    title="Chat agent"
    icon="message"
    href="/cli/agent-connections/http"
  >
    OpenAI-compatible request/response over `http(s)://`. For LLM tests, model
    benchmarks, and `--type text` simulations.
  </Card>
  <Card
    title="WebSocket agent"
    icon="microphone"
    href="/cli/agent-connections/websocket"
  >
    Real-audio pipecat frame protocol over `ws(s)://`. For `--type voice`
    simulations against a deployed pipecat agent.
  </Card>
</CardGroup>

| Type        | Description                         | Required fields            |
| ----------- | ----------------------------------- | -------------------------- |
| `chat`      | Text / OpenAI-compatible HTTP agent | `agent_url` (`http(s)://`) |
| `websocket` | Pipecat voice agent over WebSocket  | `agent_url` (`ws(s)://`)   |
