---
title: "WebSocket agent (voice)"
description: "Run voice simulations against an external pipecat agent over WebSocket"
---

Set a `ws(s)://` `agent_url` to run `--type voice` simulations against a deployed [pipecat](https://github.com/pipecat-ai/pipecat) agent. Calibrate streams real audio to it instead of running its own agent, so you don't provide `system_prompt`, `tools`, `stt`, `tts`, or `llm` — the external agent owns the pipeline. `personas`, `scenarios`, `evaluators`, and `settings` work as usual.

## Config

| Key                | Type   | Description                                                          |
| ------------------ | ------ | -------------------------------------------------------------------- |
| `agent_url`        | string | WebSocket endpoint, e.g. `ws://host:port` or `wss://host:port`        |
| `agent_serializer` | string | Wire serializer: `protobuf` (default)                                |

<Warning>
  Your agent must speak pipecat's WebSocket frame protocol with the same
  serializer (`protobuf`) and audio format. A non-pipecat socket won't work.
</Warning>

## Example

```json
{
  "agent_url": "ws://localhost:8765",
  "personas": [{ "label": "customer", "characteristics": "...", "gender": "female", "language": "english" }],
  "scenarios": [{ "name": "order inquiry", "description": "Ask about your order status." }],
  "evaluators": [{ "name": "order_resolved", "system_prompt": "...", "judge_model": "openai/gpt-4.1" }],
  "settings": { "agent_speaks_first": true, "max_turns": 5 }
}
```

```bash
calibrate simulations --type voice -c config.json -o ./out
```

Before running, Calibrate opens the WebSocket to check the endpoint is reachable (a reachability check only — it doesn't confirm the frame protocol is compatible).

## Metric differences

Because the external agent owns the pipeline, some metrics differ from the built-in agent:

- **Per-processor latency (TTFT, `processing_time`) is unavailable** — it comes from the internal pipeline.
- **`interruption_sensitivity` is no longer controlled** — it reflects the agent's own barge-in behavior.
- **Latency is measured end-to-end** from the simulator side instead.
