---
title: "HTTP agents (text)"
description: "Connect an OpenAI-compatible HTTP agent for text simulations, LLM tests, and benchmarks"
---

Set an `http(s)://` `agent_url` in your config to point Calibrate at a deployed HTTP endpoint. Used for LLM tests, model benchmarks, and `--type text` simulations.

## Config

| Key             | Type   | Description                                                              |
| --------------- | ------ | ----------------------------------------------------------------------- |
| `agent_url`     | string | Your agent's HTTP(S) endpoint, e.g. `https://your-agent.example.com/chat` |
| `agent_headers` | object | Optional auth/custom headers, e.g. `{ "Authorization": "Bearer …" }`     |

## Request & response

Calibrate `POST`s the conversation history; your agent returns a `response` (and optional `tool_calls`):

```json
// Request
{ "messages": [{ "role": "user", "content": "..." }] }
```

```json
// Response
{ "response": "...", "tool_calls": [{ "tool": "get_schedule", "arguments": {} }] }
```

The output must include `response` or `tool_calls`.

## Verify

```bash
calibrate simulations --verify --agent-url https://your-agent.example.com/chat \
  --agent-headers '{"Authorization": "Bearer YOUR_API_KEY"}'
```

## Benchmark across models

To compare LLMs, have your agent read a `model` field — Calibrate adds it to the request body (`{ "messages": [...], "model": "openai/gpt-4.1" }`). Your agent runs inference with that model.
