Connect a text chat agent to evaluate your agent's logic without placing calls by [simulating conversations](/cli/simulations) or [evaluating each turn](/cli/text-to-text).

## Quick start

- **`agent_url`** — the HTTP endpoint Calibrate sends conversation messages to.
- **`agent_headers`** — optional; auth or custom headers.

## Chat endpoint (required)

The primary URL where Calibrate sends conversation messages during a simulation. Set it as `agent_url`.

**Format:** Full HTTP(S) URL

```
https://api.yourdomain.com/chat
```

**Requirements:**

- HTTP or HTTPS (use `http://localhost:…` for a local agent)
- Reachable from where you run the CLI
- Must return a JSON response

**Example:**

```
https://api.yourdomain.com/v1/chat
```

## Authorization header

Authentication credentials sent with every request. Add them under `agent_headers` — optional, only if your agent requires auth.

**Common formats:**

**Bearer token**

```json
{ "Authorization": "Bearer your-secret-token-here" }
```

**API key**

```json
{ "X-API-Key": "your-api-key-here" }
```

## Standard protocol

The standard integration uses an HTTP, JSON-based endpoint that you provide. When running a simulation, Calibrate's simulator — acting as the user — connects to your endpoint to get responses from your agent. Requests use OpenAI-style `messages`; your endpoint replies with Calibrate's response format below.

## Chat messages

Your chat endpoint should respond to `POST` requests with a JSON body. If `agent_headers` were provided, they are included in the request.

**Request from Calibrate:**

Calibrate sends the full conversation history so far:

```json
{
  "messages": [
    { "role": "assistant", "content": "Hello! How can I help you?" },
    { "role": "user", "content": "Check order ORD-12345" }
  ]
}
```

<Note>
  When benchmarking across models, Calibrate adds a `model` field
  (`{ "messages": [...], "model": "openai/gpt-4.1" }`) so your agent can route
  to the right model.
</Note>

**Expected response format:**

Your agent must return JSON with at least one of `response` or `tool_calls`.

Standard format — a text reply:

```json
{
  "response": "Your order ORD-12345 shipped yesterday and arrives Friday."
}
```

With tool calls — include a `tool_calls` array, each item a `tool` name and `arguments` object:

```json
{
  "response": "Let me check that order.",
  "tool_calls": [
    { "tool": "get_order", "arguments": { "order_id": "ORD-12345" } }
  ]
}
```
