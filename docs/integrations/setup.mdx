---
title: "Setup"
description: "What each provider's API key is used for and how to configure it"
---

In the Calibrate app, add keys under [Bring your own keys (BYOK)](/reference/byok). With the `calibrate-agent` CLI, set each key as the environment variable shown.

## OpenRouter

Used by every evaluator, and by LLM tests, benchmarks and simulations. Get a key from [OpenRouter](https://openrouter.ai).

Environment variable: `OPENROUTER_API_KEY`

## OpenAI

Used for OpenAI speech-to-text and text-to-speech. Get a key from [OpenAI](https://openai.com).

Environment variable: `OPENAI_API_KEY`

## Deepgram

Used for Deepgram speech-to-text. Get a key from [Deepgram](https://deepgram.com).

Environment variable: `DEEPGRAM_API_KEY`

## ElevenLabs

Used for ElevenLabs speech-to-text and text-to-speech. Get a key from [ElevenLabs](https://elevenlabs.io).

Environment variable: `ELEVENLABS_API_KEY`

## Sarvam

Used for Sarvam speech-to-text and text-to-speech. Get a key from [Sarvam](https://sarvam.ai).

Environment variable: `SARVAM_API_KEY`

## Cartesia

Used for Cartesia speech-to-text and text-to-speech. Get a key from [Cartesia](https://cartesia.ai).

Environment variable: `CARTESIA_API_KEY`

## Gemini

Used for Gemini speech-to-text and text-to-speech. Get a key from [Google AI Studio](https://ai.google.dev).

Environment variable: `GOOGLE_API_KEY`

## Google Cloud

Used for Google Cloud speech-to-text and text-to-speech. Create a service account key in the [Google Cloud console](https://cloud.google.com).

In the app, paste the full service account JSON. With the CLI, set:

- `GOOGLE_APPLICATION_CREDENTIALS`: the path to the service account JSON file
- `GOOGLE_CLOUD_PROJECT_ID`: your Google Cloud project ID

## Groq

Used for Groq speech-to-text and text-to-speech with the CLI. Get a key from [Groq](https://groq.com).

Environment variable: `GROQ_API_KEY`

## Smallest AI

Used for Smallest AI speech-to-text and text-to-speech. Get a key from [Smallest AI](https://smallest.ai).

Environment variable: `SMALLEST_API_KEY`
