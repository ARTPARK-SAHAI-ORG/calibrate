<Note>
  This is the **local** toolkit (`calibrate-agent`) for benchmarking STT, TTS,
  and LLM providers and running agent simulations on your own machine. For
  the hosted CLI that runs agent tests against your deployed agents, see the
  [CLI](/cli/overview) tab.
</Note>

## Installation

```bash
pip install calibrate-agent
```

## Get started

Calibrate provides the following commands:

| Command                                                       | Description                                    |
| ------------------------------------------------------------ | ---------------------------------------------- |
| `calibrate-agent stt -p deepgram google -i ./data -o ./out`  | STT evaluation — benchmark providers           |
| `calibrate-agent tts -p openai google -i sample.csv -o ./out`| TTS evaluation — benchmark providers           |
| `calibrate-agent llm -c config.json -m openai/gpt-4.1`       | LLM evaluation — test agent responses          |
| `calibrate-agent simulations --type text -c config.json`     | Text or voice simulations                      |
| `calibrate-agent general --dataset data.json -c config.json` | Score arbitrary `{id, input, output}` pairs with an LLM judge |
| `calibrate-agent status`                                     | Check API key configuration and connectivity   |

Run `calibrate-agent <command> -h` to see all options for a command. Pass `calibrate-agent status --table` to print connectivity as a table instead of JSON.

### General task evaluation

`calibrate-agent general` scores arbitrary input/output pairs with an LLM judge — useful for evaluating any task that isn't STT, TTS, or a conversation.

```bash
calibrate-agent general --dataset data.json -c config.json -o ./out
```

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `--dataset` | string | — | JSON list of `{id, input, output}` rows to score. |
| `-c, --config` | string | — | JSON config defining the `evaluators` list (same evaluator shape as the other commands). |
| `-o, --output-dir` | string | `./out` | Where results are written. |
