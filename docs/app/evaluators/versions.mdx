Every change to how an evaluator judges is saved as a new version: v1, v2, v3 and so on. The old versions stay, so you can go back to one.

## Open the evaluator page

In the sidebar, click **Evaluators**. Click the evaluator, then click **Open**. The page below is for "Explains step by step", which is under **Agent simulations** → **Evaluators**. Every evaluator page works the same way.

<Frame>
  <img src="/images/app/evaluators-detail-versions.png" alt="The Explains step by step page with versions v2 and v1 on the Prompts tab" />
</Frame>

The page has two tabs:

- **Prompts** lists the versions. Click a version to see its model, its prompt and its output labels.
- **Agreement** shows how often the evaluator agrees with people who labelled the same replies. See [Check how well an evaluator agrees with people](/app/human-alignment/agreement).

## Rename an evaluator

Click the pencil next to the evaluator's name. In the **Edit evaluator** window, change the **Name** or the **Description**, then click **Save**.

<Frame>
  <img src="/images/app/evaluators-edit.png" alt="The Edit evaluator window with Name and Description boxes" />
</Frame>


A new name or description does not make a new version.

## Change the prompt

Click **Edit** at the top of the page. The **New version** window opens, starting from the current version.

To start from an older version, click the document icon on that version in the list. Its tooltip reads "Edit, starting from" followed by the version, for example "Edit, starting from v1".

In the **New version** window you can change:

- **Judge prompt**, the question the judge answers.
- **Labels** for a binary evaluator, or **Rating scale** for a rating evaluator.
- **Judge model**.
- **Summary of change**, an optional note on what you changed.

Variable names stay the same as when the evaluator was created. You can change each variable's description.

**Mark the new version as the live version** is ticked by default. Leave it ticked to use the new version straight away, and click **Create and mark live**. Untick it to save the version without using it, and click **Create version**.

<Frame>
  <img src="/images/app/evaluators-new-version.png" alt="The New version window with the judge prompt, labels, summary of change, live version tick box and judge model" />
</Frame>


## Choose the current version

One version carries the **Current** label. New tests use the current version.

To make an older version current, click the tick on that version in the list. Its tooltip reads **Mark as current**.

<Frame>
  <img src="/images/app/evaluators-mark-current.png" alt="The Mark as current tooltip on version v1" />
</Frame>


For example, if v2 of "Explains step by step" fails replies that v1 passed correctly, mark v1 as current again.

## Delete a version

Click the bin on a version in the list, then click **Delete** to confirm. You cannot delete the current version. Mark another version as current first.

<Frame>
  <img src="/images/app/evaluators-delete-version.png" alt="The Delete version window asking to confirm deleting v1" />
</Frame>


## Duplicate an evaluator

Click **Duplicate** at the top of the page or on the evaluator's card in the list. The create form opens filled in from the current version, named "Copy of" followed by the original name. Change what you need and click **Create evaluator**. The copy is a separate evaluator with its own versions.

<Frame>
  <img src="/images/app/evaluators-duplicate.png" alt="The Add evaluator form filled in with the name Copy of Explains step by step" />
</Frame>


## Delete an evaluator

Click the bin at the top right of the evaluator page, then click **Delete** to confirm. You can also click **Delete** on the evaluator's card in the list.

<Frame>
  <img src="/images/app/evaluators-delete.png" alt="The Delete evaluator window asking to confirm deleting Explains step by step" />
</Frame>


Deleting an evaluator removes it from everywhere it is used. This cannot be undone. Some pre-built evaluators cannot be deleted, so they have no delete button.
