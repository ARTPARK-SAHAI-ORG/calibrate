This page creates the two evaluators the Maths homework tutor uses: "Step-by-step reply" and "Warm tone". To learn what an evaluator is first, see [Evaluators overview](/app/evaluators/overview).

## Open the create form

In the sidebar, click **Evaluators**, then click **Create evaluator**.

A window asks **What is this evaluator for?**

<Frame>
  <img src="/images/app/evaluators-create.png" alt="The window that asks what the evaluator is for" />
</Frame>

Pick the card that matches your agent:

- **Conversation**: your agent has a conversation with a user. The evaluator judges the agent's next reply. Pick this for the Maths homework tutor.
- **Basic**: your agent takes an input and gives an output.

Click **Continue**. The **Add evaluator** form opens. Calibrate fills in a starting judge prompt and judge model for the kind you picked. You can change both.

## Fill in the form

### Name

Type a name, for example `Step-by-step reply`. Every evaluator needs its own name. If another evaluator already has it, the form says "An evaluator with this name already exists". The words `name` and `conversation_history` cannot be used as names.

### Description

Optional. One line that shows under the name in the list, for example `Checks the tutor teaches the next step instead of giving the answer`.

### Review type

Choose **Binary** or **Rating**.

- **Binary** returns a pass or fail. Under **Labels**, the **True** row and the **False** row show "Correct" and "Wrong" until you type your own labels. Under each label you can add what a reply needs to get it. "Step-by-step reply" uses **Binary**.
- **Rating** returns a score. Under **Rating scale**, each row has a number and a label. The highest number is the best and the lowest is the worst. You need at least two rows, and every row needs a label. Click **Add row** to add more. "Warm tone" uses **Rating**, with rows 1 to 5.

### Judge model

Click the box under **Judge model** to choose the AI model that does the judging.

### Judge prompt

Write what the judge should check. Keep it to one clear question.

For "Step-by-step reply":

```text
Does the tutor explain the next step instead of giving the final answer straight away?
```

For "Warm tone":

```text
How encouraging and patient is the tutor's reply? 1 is dismissive, 5 is warm and patient.
```

<Tip>
  To reuse one evaluator across tests with a different value in each test, put a variable in the prompt, such as `{{ topic }}`. A **Variables** list then appears above the prompt. Give each variable a short description. When you add the evaluator to a test, you fill in that test's value. Variables can only be added when you first create the evaluator.
</Tip>

## Save the evaluator

Click **Create evaluator**. If a required field is empty, it is outlined in red and nothing is saved. Fill it in and click **Create evaluator** again.

The evaluator appears in the list. Its first version is v1. To change it later, see [Edit an evaluator and manage versions](/app/evaluators/versions).
