## Usage

```python
from calibrate import Calibrate, BulkTestItem

client = Calibrate(
    api_key="your_api_key",
)

client.tests.bulk_create(
    type="response",
    tests=[
        BulkTestItem(
            name="name",
        )
    ],
)
```
