## Install

```bash
pip install calibrate-sdk
```

## Quick start

```python
from calibrate import Calibrate

client = Calibrate(api_key="sk_your_api_key")

for agent in client.agents.list():
    print(agent.uuid, agent.name)
```

## Auth

Create an API key under **Workspace settings → API keys** — see the [API keys guide](/reference/api-keys).

```python
from calibrate import Calibrate

client = Calibrate(api_key="sk_your_api_key")
```

The SDK sends `X-API-Key` on every request.

<Warning>
  The raw key is shown exactly once at creation. Store it in a secret manager or CI variable — never commit it.
</Warning>
