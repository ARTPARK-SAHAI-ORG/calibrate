## Usage

```python
from calibrate import Calibrate, EvaluatorVersionCreate

client = Calibrate(
    api_key="your_api_key",
)

client.evaluators.create(
    name="name",
    version=EvaluatorVersionCreate(
        judge_model="judge_model",
        system_prompt="system_prompt",
    ),
)
```
