---

Each score compares a provider's transcript, the **Prediction**, with the words you typed for that recording, the **Ground Truth**. The **About** tab on a results page explains every score that run produced.

## Word error rate (WER)

WER counts the words in the transcript that differ from the words you typed. A word can be wrong, missing, or extra. The count is divided by the number of words you typed.

- Range: 0 and up. 0 means every word matches. Lower is better.
- Every run measures it.

| Words spoken | Transcript | WER |
| --- | --- | --- |
| मुझे भिन्न समझ नहीं आते | मुझे भिन्न समझ नहीं आते | 0.0 |
| आधा और एक चौथाई जोड़ो | आधा और 1 चौथाई जोड़ो | 0.2 |
| तीन बटा पाँच में एक बटा पाँच जोड़ने पर क्या आएगा | तीन बटा पाँच में दो बटा पाँच जोड़ने पर क्या आएगा | 0.09 |

The second and third rows show the limit of WER. In the second row, "1" and "एक" mean the same thing, but WER counts it as a wrong word. In the third row, "दो" changes the question, yet its WER is lower.

## Character error rate (CER)

CER works the same way as WER, but counts letters instead of words. A small change inside a long word costs less than with WER. This helps with Hindi and other Indian languages, where one long word can carry a lot of meaning.

- Range: 0 and up. 0 means every letter matches. Lower is better.
- Every run measures it.

## Meaning-based scores

These scores appear when **Use built-in LLM-based evaluation metrics** is on in the **Evaluators** tab of a new evaluation. It is on by default. An AI model reads each transcript next to the words you typed and judges the meaning.

| Score | What it shows | Range |
| --- | --- | --- |
| LLM-WER | WER again, but words that mean the same thing are not counted as errors. This covers numbers written as digits or words, other spellings, and other scripts. | 0 and up, lower is better |
| LLM-CER | The same idea for letters. | 0 and up, lower is better |
| Intent Score | Whether the transcript keeps what the student meant. It fails when, for example, a number changes or a question turns into a statement. | Pass or fail |
| Entity Score | The share of names, places, dates, times and numbers that came through correctly. | 0 to 1, higher is better |

In the WER table above, the second row would get an LLM-WER of 0, because "1" and "एक" mean the same thing. The third row still counts as an error, because "दो" changes the question.

## Your own evaluators

You can also add evaluators that score each transcript in your own way. Click **Add evaluators** on the **Evaluators** tab of a new evaluation. Each evaluator gets its own column on the **Leaderboard** and **Results** tabs. See [Create an evaluator](/app/evaluators/create).
