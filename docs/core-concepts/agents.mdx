Build your agent in Calibrate when you want to try a prompt and a model without running your own server. This page builds the Maths homework tutor.

<Tip>
  Your agent already runs somewhere else? See [Connect your own
  agent](/core-concepts/agent-connections).
</Tip>

## Create the agent

1. From the sidebar, click **Agents** → **New agent**.
2. Under **Agent name**, type `Maths homework tutor`.
3. Under **Setup**, select **Build your agent in Calibrate**.

<Frame>
  <img src="/images/app/agents-new-agent-build.png" alt="The New agent dialog with Build your agent in Calibrate selected" />
</Frame>

4. Click **Next**.
5. Select **Conversation**, then click **Create**.

The agent page opens on the **Agent** tab.

## Write the system prompt and pick the models

<Frame>
  <img src="/images/app/agents-agent-tab.png" alt="The Agent tab of the Maths homework tutor, with its system prompt on the left and the three model choices on the right" />
</Frame>

**System prompt** is where you tell the agent who it is and how to behave. The tutor's prompt is:

```text
You are a friendly maths tutor for class 6 students in India. Explain one step at a time in simple words. Reply in the language the student uses (English or Hindi). Never give the final answer straight away: ask the student to try the next step first. If the student is upset, encourage them before continuing.
```

<Tip>
  Write down the tone, what the agent should do, and what it must never do. Each
  rule you write here is something you can test later.
</Tip>

On the right, pick three models:

- **Speech To Text**: the provider that turns the student's voice into text. The tutor uses Sarvam.
- **Text To Speech**: the provider that turns the tutor's reply into voice. The tutor uses Sarvam.
- **LLM**: the model that writes the replies. Click the box and search for a model. The tutor uses `openai/gpt-4.1-mini`.

Calibrate uses the speech models only in voice simulations. Tests and text simulations use the LLM alone.

Click **Save** at the top right.

## Set how the conversation runs

Click the **Settings** tab.

<Frame>
  <img src="/images/app/agents-settings.png" alt="The Settings tab of the Maths homework tutor" />
</Frame>

- **Agent speaks first**: turn this on if the agent should start the conversation. The tutor greets the student first.
- **Max assistant turns**: the most replies the agent gives before the call ends. The default is 50.
- **Enable continuous monitoring**: scores conversations from your live agent with the evaluators on the **Evaluators** tab. See [Monitor live conversations](/app/agents/monitoring).

Click **Save** at the top right.
