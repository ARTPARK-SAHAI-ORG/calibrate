A tool is something your agent can call during a conversation. Calibrate has two kinds:

- **Structured output tool**: the agent pulls set details out of the conversation, in a format you define.
- **Webhook tool**: the agent calls an outside web address to do something or look something up.

This page adds two tools to the Maths homework tutor:

- `save_progress`, a structured output tool that saves which topic the student practised and whether they solved the question.
- `get_practice_question`, a webhook tool that fetches one practice question for a topic.

## Open the Tools tab

On the agent page, click the **Tools** tab.

<Frame>
  <img src="/images/app/agents-tools-tab.png" alt="The Tools tab of the Maths homework tutor, listing get_practice_question and save_progress" />
</Frame>

- **Add tool** adds a tool that already exists in your workspace.
- **Create tool** makes a new tool and adds it to this agent.

To make a new tool, click **Create tool**. Calibrate asks what the tool should do. Pick **Structured output tool** or **Webhook tool**.

## Structured output tools

A structured output tool lets the agent pull details out of the conversation in a fixed shape. The tutor uses `save_progress` to note the topic and whether the student got the answer.

<Frame>
  <img src="/images/app/agents-add-tool-structured-output.png" alt="The Add structured output tool form" />
</Frame>

Fill in **Configuration**:

- **Name**: `save_progress`
- **Description**: tell the LLM when to call the tool and what to pass. For example: `Save which topic the student practised and whether they solved the question.`

Under **Parameters**, define each detail the agent should fill in. Click **Add param** for each one. For every parameter, set:

- **Data type**: **String**, **Number**, **Integer**, **Boolean**, **Object** or **Array**.
- **Name**: what the detail is called.
- **Required**: tick it if the agent must always fill it in.
- **Description**: tell the LLM what this detail means and how to fill it in.

The tutor's two parameters:

| Data type | Name | Description |
| --- | --- | --- |
| String | `topic` | The maths topic, for example fractions |
| Boolean | `solved` | True if the student reached the right answer |

Click **Add tool**.

## Webhook tools

A webhook tool lets the agent call a web address on your side. The tutor uses `get_practice_question` to fetch a question for the topic the student is working on.

<Frame>
  <img src="/images/app/agents-add-tool-webhook.png" alt="The Add webhook tool form" />
</Frame>

Fill in **Configuration**:

- **Name**: `get_practice_question`
- **Description**: tell the LLM when to call the tool and what to pass. For example: `Fetch one practice question for a topic.`
- **Method**: how the request is sent. Pick **GET**, **POST**, **PUT**, **PATCH** or **DELETE**. The tutor uses **GET**.
- **URL**: the web address to call. The tutor uses `https://example.org/tutor/practice-question`.
- **Response timeout (seconds)**: how long to wait for an answer. The default is 20 seconds.

Then fill in the parts of the request your web address needs:

- **Headers**: values sent with every request, such as a key your service checks. Click **Add header** for each one.
- **Query parameters**: details the LLM fills in and adds to the URL. Click **Add param** for each one. The tutor has one, `topic`, a **String** described as "The maths topic".
- **Body parameters**: details the LLM fills in and sends in the request body. This section appears only for **POST**, **PUT** and **PATCH**.

Click **Add tool**.

<Tip>
  Both forms have a **Form** view and a **JSON** view at the top right. Use
  **JSON** to paste a tool you already wrote out.
</Tip>

## In-built tools

Every agent has these tools. They are listed under **In-built tools** on the **Tools** tab.

| Tool | What it does |
| --- | --- |
| **End conversation** | Lets the agent end the call |
