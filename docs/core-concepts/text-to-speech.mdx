## Metrics

The **About** tab on a results page explains every score that run produced.

### Evaluators

An evaluator listens to the recording a provider made and judges it against the text it was given. It does not turn the speech back into text first.

Every new evaluation starts with the Pronunciation evaluator added on the **Evaluators** tab. It checks that the spoken words match the text and are clear enough to understand. Each recording gets a pass or a fail, with a short reason.

| Text | What the evaluator heard | Result |
| --- | --- | --- |
| बहुत बढ़िया! तुमने सही जवाब दिया। | Every word spoken clearly and correctly | Pass |
| चलो साथ में करते हैं। 1/2 में कितने 1/4 होते हैं? | "1/4" read out as "one by four" instead of "एक बटा चार" | Fail |

The leaderboard shows, for each provider, the share of recordings that passed. Higher is better.

A run needs at least one evaluator. To score something else, such as how natural the voice sounds, click **Add evaluators** on the **Evaluators** tab of a new evaluation. See [Create an evaluator](/app/evaluators/create).

### Latency

Latency is the time, in seconds, from asking a provider for speech until the first part of the audio arrives. The leaderboard shows it as **Latency (s)**. Each provider's number is the middle value across all lines of text.

- Range: 0 and up. Lower is better.
- Every run measures it.

Latency matters for a voice agent, because a student waits this long before hearing the tutor start to speak.

## Datasets

A dataset is a set of lines of text for the providers to read aloud. You can run many evaluations on the same dataset.

### See your datasets

In the sidebar, click **Text-to-Speech**, then click the **Datasets** tab. Each row shows how many lines the dataset has (**Items**) and how many evaluations used it (**Evals**).

### Create a dataset

1. On the **Datasets** tab, click **New dataset**.
2. Under **Dataset name**, type a name, for example `Tutor replies in Hindi`, and click **Create**.
3. On the dataset page, type a line of text in the first row.
4. Click **Add another row** for each other line. To add many at once, click **Choose CSV** in the **Upload CSV** box.
5. Click **Save**.

Each line can be up to 200 characters long.

A dataset is also created when you enter text on the **Dataset** tab of a new evaluation.

### Change a dataset

Click a dataset on the **Datasets** tab to open it. On the dataset page you can:

- Add lines with **Add another row** or **Choose CSV**.
- Change a line by typing in its box.
- Remove a line with the bin button on its row. The button shows once your other changes are saved, and only while the dataset has more than one line.
- Rename the dataset with the pencil button next to its name.

Click **Save** to keep your changes.

### Run an evaluation on a dataset

On the dataset page, click **New evaluation**. The dataset is already chosen, so you only pick the language and providers. Save any changes first.

### Delete a dataset

On the **Datasets** tab, click the bin button at the end of the dataset's row. This cannot be undone.
