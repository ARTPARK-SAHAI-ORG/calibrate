---
title: "Rate limits"
description: "The rate limits on your workspace"
---

Calibrate runs your evaluations using AI providers such as OpenRouter and Deepgram. By default, Calibrate uses its own API keys for these providers and pays for the usage, so the rate limits are lower. If you [add your own API keys](/reference/byok) for these providers, your provider accounts pay instead and two of the rate limits are removed.

| Rate limit | Default | With your own provider keys |
| --- | --- | --- |
| Rows in one evaluation run | 20 | No limit |
| Production traces scored automatically, counted over the lifetime of your workspace | 100 | No limit |
| Production traces stored | 50,000 | 50,000 |

A production trace is one input your agent received in production and the output it gave. See [Monitor your agent in production](/app/agents/monitoring).

## How rows are counted

- **Test run:** one row per test.
- **Benchmark:** the number of tests multiplied by the number of models.
- **Evaluator run on an annotation task:** the number of items multiplied by the number of evaluators.

## What happens when you go over a rate limit

- **Rows in one evaluation run:** the run does not start and the request returns a `400` error. If you run many agents at once with `POST /agent-tests/run`, an agent over the rate limit appears under `skipped` with the reason `over_row_limit`, and the other agents still run.
- **Production traces scored:** the trace is stored but not scored.
- **Production traces stored:** `POST /traces` returns a `429` error until you delete some.

## Runs at the same time

Your workspace can run only a limited number of evaluation runs at the same time, with either kind of key. A new run over that rate limit waits in a queue and starts when an earlier run finishes.

## Using your own provider keys

[Bring your own keys (BYOK)](/reference/byok) removes the rate limits on rows in one evaluation run and on production traces scored. Once you add any provider key, every run in your workspace uses only your keys and is billed to your provider accounts.
