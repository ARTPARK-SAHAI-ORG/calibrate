## Why use your own keys?

### Billing

Evaluation runs are billed to your own provider accounts.

### No limits on evaluation runs

On Calibrate's default keys, your workspace has two limits:

- The number of rows a single evaluation run can process.
- The number of [live conversations](/app/agents/monitoring) Calibrate scores automatically.

With your own keys, both limits are removed. The limit on how many live conversations your workspace can store stays the same.

## Add a key

1. [Open settings](/app/workspace-settings/settings#open-settings).
2. Click the **Bring your own keys (BYOK)** tab.
3. Paste a provider's API key into its field. See [Setup](/integrations/setup) for how to get a key from each provider.
4. Click **Save** next to the field. For your first key, click **Save the key** to confirm. Calibrate checks the key with the provider before saving it.

**OpenRouter** under **Language models** is used by every evaluator, and by LLM tests, benchmarks and simulations. The providers under **Voice evaluation** are used for speech-to-text, text-to-speech and voice simulations.

### Add a missing key while you set up a run

Once your workspace uses its own keys, the **Speech-to-Text** and **Text-to-Speech** pages mark a provider without a key as **API key needed**. Select that provider and a key field opens under it. Paste the key and click **Save**.

## How keys are used

- Once you add any key, every run in your workspace uses only your keys.
- A run that needs a provider you have not added a key for starts and then fails.
- If you remove all your keys, runs go back to Calibrate's default keys and their limits.
