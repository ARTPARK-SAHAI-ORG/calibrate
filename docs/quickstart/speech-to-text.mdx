A speech-to-text provider turns what a student says into text that your agent reads. This guide compares three providers on short questions a class 6 student asks the Maths homework tutor in Hindi.

You need a few short recordings, each a `.wav` file of under 60 seconds and under 5 MB, and the exact words spoken in each one.

## Start an evaluation

In the sidebar, under **Voice evaluation**, click **Speech-to-Text**. Then click **New evaluation**.

<Frame>
  <img src="/images/app/stt-start.png" alt="The Evaluations tab of the Speech-to-Text page, with the New evaluation button at the top right" />
</Frame>

## Add your recordings

The **Dataset** tab opens first. Keep **Upload new** selected.

<Frame>
  <img src="/images/app/stt-new-evaluation.png" alt="The Dataset tab of a new speech-to-text evaluation, with a row for a recording and an Upload ZIP box" />
</Frame>

1. Under **Dataset name**, type `Tutor questions in Hindi`.
2. In the first row, click **Upload .wav** and pick a recording.
3. In the box next to it, type the exact words spoken, for example `मुझे भिन्न समझ नहीं आते`.
4. Click **Add another sample** for each other recording. This example has three:

| Recording | Words spoken |
| --- | --- |
| `question_1.wav` | मुझे भिन्न समझ नहीं आते |
| `question_2.wav` | आधा और एक चौथाई जोड़ो |
| `question_3.wav` | तीन बटा पाँच में एक बटा पाँच जोड़ने पर क्या आएगा |

The recordings are saved as a dataset with this name, so you can use them again in later evaluations. Your datasets are listed on the **Datasets** tab of the **Speech-to-Text** page.

<Frame>
  <img src="/images/app/stt-datasets.png" alt="The Datasets tab of the Speech-to-Text page, listing Tutor questions in Hindi with 3 items" />
</Frame>

<Accordion title="Upload many recordings at once" icon="file-zipper">
  In the **Upload ZIP** box, click **Choose ZIP file**. The ZIP file holds an `audios` folder with your `.wav` files and a `data.csv` file with two columns:

  ```csv
  audio_file,text
  question_1.wav,मुझे भिन्न समझ नहीं आते
  question_2.wav,आधा और एक चौथाई जोड़ो
  question_3.wav,तीन बटा पाँच में एक बटा पाँच जोड़ने पर क्या आएगा
  ```

  Click **Download sample ZIP** to get a ZIP file in the right shape.
</Accordion>

<Tip>
  To run on recordings you already uploaded, click **Use existing dataset** and pick the dataset from the list.
</Tip>

## Choose the providers

1. Click the **Models** tab.
2. Under **Language**, pick **Hindi**. The list shows only providers that support Hindi.
3. Under **Select providers to evaluate**, tick Sarvam, Deepgram and Google. Each row shows the model that provider uses.

<Frame>
  <img src="/images/app/stt-models.png" alt="The Models tab with Hindi chosen as the language and a list of providers, most marked API key needed" />
</Frame>

If your workspace uses its own provider keys, a provider without a key shows **API key needed**. Tick it, paste the key in the field that opens under it, and click **Save**. The key is saved for the whole workspace. See [Bring your own keys (BYOK)](/reference/byok).

## Choose how transcripts are scored

Click the **Evaluators** tab.

<Frame>
  <img src="/images/app/stt-evaluators-tab.png" alt="The Evaluators tab of a new speech-to-text evaluation, with the built-in LLM-based evaluation metrics switched on and no evaluators added" />
</Frame>

Every run measures WER (Word Error Rate) and CER (Character Error Rate). These count how many words and letters in each transcript differ from the words you typed.

**Use built-in LLM-based evaluation metrics** is on by default. It adds scores that judge the meaning of each transcript, not only exact word matches. Keep it on for Hindi and other Indian languages.

To score transcripts with your own evaluator as well, click **Add evaluators**. See [Speech-to-text metrics](/core-concepts/speech-to-text) for what each score means.

## Run the evaluation

Click **Evaluate** at the top of the page. The results page opens and fills in as each provider finishes.

<Frame>
  <img src="/images/app/stt-running.png" alt="The results page for Tutor questions in Hindi while it is running, with a tick next to each provider that has finished" />
</Frame>

## Read the results

The **Leaderboard** tab puts the providers side by side, with one chart for each score. Lower WER and CER are better.

<Frame>
  <img src="/images/app/stt-results.png" alt="The Leaderboard tab for Tutor questions in Hindi, comparing WER, CER, LLM-WER and LLM-CER for Sarvam, Deepgram and Google" />
</Frame>

In this example Sarvam gets the fewest words wrong, with a WER of 0.08.

The **Results** tab shows every recording. Pick a provider on the left. Each row has the recording to play, the **Ground Truth** you typed, the provider's **Prediction**, and the scores for that row.

The **About** tab explains each score shown on the page.

## Export and share the results

- **Export results** downloads a ZIP file. It holds a CSV file with every provider's transcript and scores for each recording, and an `audios` folder with the recordings.
- **Download CSV** on the **Leaderboard** tab downloads the leaderboard table.
- **Share** makes the results page public. Click **Copy link** to copy the link. Anyone with the link can see the results without a Calibrate account. Click **Public** to make the page private again.
- **Submit for labelling** sends rows you ticked on the **Results** tab to a labelling task, so people can check the transcripts. See [Create a labelling task](/app/human-alignment/labelling-tasks).
